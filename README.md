# 🎴 Flashcards Japonés - App de Aprendizaje

Aplicación web desarrollada para facilitar el aprendizaje de vocabulario japonés mediante el sistema de tarjetas de estudio (flashcards). 

## 🚀 Tecnologías Utilizadas
* **Frontend:** Angular
* **Backend / Scripts:** Python
* **Diseño:** HTML5, CSS3, Diseño Responsivo

## 💡 Funcionalidades Principales
* Interfaz interactiva para el repaso de vocabulario.
* Gestión dinámica de componentes y estado con Angular.
* Integración de funciones en Python para el procesamiento de datos.

## 🛠️ Contexto del Proyecto
Este proyecto fue creado con el objetivo de combinar el desarrollo de interfaces dinámicas en Angular con la versatilidad de Python. Demuestra la capacidad de integrar diferentes lenguajes y frameworks para construir una herramienta educativa funcional y ágil.
